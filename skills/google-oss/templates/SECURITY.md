# Security Policy

## Reporting a Vulnerability

To report a security issue, please use <https://g.co/vulnz>. We use g.co/vulnz for our intake and do coordination and disclosure here on GitHub (including using GitHub Security Advisories).

The Google Security Team will respond within 5 working days of your report on g.co/vulnz.

Please **do not** open a public GitHub issue for suspected security vulnerabilities.
